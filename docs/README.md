# NOAA It All Documentation

> [!NOTE]
> This integration and its developer are independent and are not affiliated, endorsed, or sponsored by NOAA in any way.

NOAA It All brings NOAA and National Weather Service data into Home Assistant as sensors, binary
sensors, images and a weather entity: weather for your location, surf for any coast, Great Lakes
nearshore marine forecasts, hurricanes and satellite images, and space weather, aurora, meteor
showers and eclipses. To install it, see the [README](../README.md#installation).
